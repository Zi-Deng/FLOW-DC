# agentic-review

Use workflow.py review PR with the current issue/plan and explicit provider/model when overriding defaults. Read PROVIDERS.md only for setup. Tests execute separately. Record head/base, CLI/provider/model, findings, reported scope, limits and actual status. No exhaustive coverage claim or paid capability campaign. Publish COMMENT only; refuse stale reports. No automatic paid replay/fallback.

Follow [the streamlined guide](../../../docs/agent-workflow/OPERATING-GUIDE.md). User instructions and existing authorization take precedence. Keep credentials/private material separate and scientific validity distinct from software checks.
