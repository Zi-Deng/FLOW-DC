# Workflow skills

Eight short phase skills support capture, planning, preparation, implementation, review, repair, finish and lifecycle coordination. Read only the relevant phase. They share [the current operating guide](OPERATING-GUIDE.md); no repeated instruction stack is required.

Implement and repair directly in the assigned worktree. A separate executor and same-session continuity are optional. User authorization persists. Private memory aids continuity; it never enters independent review. GitHub issue/PR records describe public work, without per-phase proof generations.

One local check pass, current CI and a bounded independent static review suffice for substantive software changes. Scientific evidence follows its own research protocol. Historical source/reports are not active compatibility gates.
