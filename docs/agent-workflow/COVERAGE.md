# Review scope and limitations

The maintainer retired exhaustive, mechanically verified line-coverage readiness on October9,2026. Use one ordinary independent static review of changed behavior and relevant dependencies/tests. The reviewer reports inspected paths and important omissions; those are self-reports, not proof of understanding or complete inspection.

Missing material, quota, masking, malformed output, interruption and incomplete execution remain visible. A completed model process is not comprehensive validation. No historical report is promoted to current review. Tests, actual CI checkout, scientific evidence and clean reproduction remain separate facts.

Old source is retained in Git history and old private reports outside active runtime. There is no requirement to execute old adapters/tests or reconstruct generation histories. See [current procedure](REVIEW.md).
