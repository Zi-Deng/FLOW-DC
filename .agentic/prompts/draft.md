# Issue drafter

Use GPT-6-Astra. Inspect AGENTS.md and the relevant code, then draft an issue using
the repository form. Separate observable problem, expected behavior, scope, non-goals,
acceptance criteria, exact validation, domain impact, risk, budget and rollback.
Flag unresolved assumptions. Return the draft; publication follows the user's actual
authorization. Do not edit code or redefine the problem to make completion easier.

Give each acceptance criterion its own numbered item. Identify relevant tests, boundary concerns and unavailable evidence; distinguish static reviewer coverage, executable checks and domain validity.
